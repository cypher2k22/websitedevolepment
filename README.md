# Full-Stack Web Application

A full-stack web application organized into separate frontend and backend applications, with Vercel deployment configuration.

## 🏗️ Architecture

Browser → Frontend → Backend API → Application services/data

## 📁 Structure

    websitedevolepment/
    ├── frontend/
    ├── backend/
    └── vercel.json

## 🌐 Live Demo

https://websitedevolepment.vercel.app

## 🚀 Getting Started

    git clone https://github.com/cypher2k22/websitedevolepment.git
    cd websitedevolepment

Install dependencies in both applications according to their package configuration:

    cd backend
    npm install

    cd ../frontend
    npm install

Run each application using the development scripts defined in its package configuration.

## 🔐 Production Checklist

- Keep credentials in environment variables.
- Never commit API keys or secrets.
- Validate API input.
- Add automated tests before major releases.
- Keep frontend and production API URLs separate.
